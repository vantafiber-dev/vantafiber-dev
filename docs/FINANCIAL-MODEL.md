# Vanta Fiber - Financial Model

## Unit economics

net_receipts = gross_payments - processor_fees - refunds - chargebacks - taxes_collected_remitted - affiliate_commissions.
operating_contribution = net_receipts + other_net_revenue - hosting - infrastructure - prizes - moderation - software - compliance.

## Scenarios

Conservative, base and stretch. No invented uptake, pricing, current Nitrado app costs or payment fees.

## Controls

1. Track settled funds separately from checkout totals; account balance separately from spendable cash.
2. Compute contribution before reserve transfers; compute cash available after reserves, tax and refund
   obligations.
3. Cap each payment campaign by fulfilment capacity.

## Gates

No public fundraising campaign before legal, platform and policy review. No live sale before
compliance signoff.
