# Vanta Fiber - Incident Response

## Severity classes

Minor, major, critical; with communication drafts, owner approval gates and restoration tests.

## Scenarios

1. Raid-night crash: protect evidence, announce expectations, evaluate known snapshots, avoid
   attributing cause before data supports it, verify results after reopen.
2. Provider outage, missed poll, stale status, uncertain live data.
3. Abuse spike, staff misconduct, provider suspension, founder unavailable for 48 hours.

## Recovery

- Status changes: planned maintenance, unknown, stale, confirmed outage stay distinct.
- After a missed poll, display last known state as stale; never use poller failure as proof of outage.
