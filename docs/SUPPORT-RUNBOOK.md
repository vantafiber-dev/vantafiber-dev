# Vanta Fiber - Support Runbook

## Ticket flow

Player files ticket -> moderator claims and records evidence -> reviewer closes ->
player receives private status update or can appeal.

## Requirements

1. Permission checks on server-side routes, not only hidden buttons.
2. Abuse-resistant attachments, size/type validation, quarantine before viewing.
3. Case owners, clear closure expectations, appeal process.
4. Audit logs with controlled retention.

## Escalation

- Duplication suspicion, griefing report, harassment, exposed token, Discord raid, chargeback,
  corrupt backup, economy discrepancy, accidental staff ban, false-positive appeal, cancelled creator
  collaboration, prelaunch funding failure, downtime before paid event, voluntary termination.
