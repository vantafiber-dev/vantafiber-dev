# Vanta Fiber - Hosting Reality

## Zero-dollar first

- GitHub for source, CI within free limits; GitHub Pages reserved for permissible static content.
- Cloudflare or equivalent for commercial frontend if terms permit; Workers for signed Discord HTTP
  interactions; D1 or alternative database; Turnstile; cron triggers.
- Supabase Free as an alternative PostgreSQL/Auth/storage option with inactivity pausing caveats.

## Paid lines that may require real expenditure

- Xbox ASE game hosting, payment processing, some operational services.
- Durable paid alternative when continuous processing or reliability exceeds free constraints.

## Provider path

- Nitrado Xbox ASE hosting via the Microsoft app for boosts/eligibility; confirm current
  eligibility before designing live flows.

## Cost control

- Decision gates require quote, spend cap, written cancellation date and owner approval.
- Reserve policy, runway tracking and refund contingency plans required before fundraising.
