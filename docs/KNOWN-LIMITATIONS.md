# Vanta Fiber — Known Limitations

1. Public site runs on fixture/local data; no durable shared waitlist backend yet.
2. No live Xbox ASE hosting capacity purchased; status board is not live.
3. Hosted checkout disabled; payment capability prohibited pending compliance signoff.
4. Anti-cheat permanent ban automation disabled; human sign-off required.
5. No real Discord application, bot token or gateway deployment yet.
6. No real Nitrado credentials; provider adapter gated.
7. Legal terms drafts are not final legal advice.

## Acceptance boundary

A polished simulator is a useful deliverable but is not the live server business. A tested
website is not evidence of an Xbox integration. A written runbook is not evidence of a drill.
